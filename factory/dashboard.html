Laravel Software Factory

Mode: manual

How to use
  • ./factory/bin/factory mode auto — autonomous pipeline
  • ./factory/bin/factory mode manual — interactive Grill
  • ./factory/bin/factory run — process queue (auto)
  • ./factory/bin/factory grill — start Grill (manual)
  • ./factory/checks.sh — run the gate
Job state

Place job records in docs/context/jobs/ or as comments on GitHub issues. This dashboard is a starting point — extend it to read those files.
