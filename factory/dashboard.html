Laravel Software Factory

Production-grade agentic pipeline · Model-agnostic · GitHub-centric

Mode

Current default: manual

  • ./factory/bin/factory mode auto — autonomous pipeline
  • ./factory/bin/factory mode manual — interactive Grill
Commands
  • ./factory/bin/factory run <issue> — prepare a job (auto)
  • ./factory/bin/factory status — list jobs
  • ./factory/bin/factory grill — start Grill (manual)
  • ./factory/bin/job create|update|show|list — manage job state
  • ./factory/checks.sh — run the deterministic gate
Pipeline

Grill / Intake → Spec → Tickets → Implement (worktrees) → Gate → Review (risk-routed) → Approver → Human merge

Job state

Live jobs live in docs/context/jobs/. Run ./factory/bin/job list or open those files.

This dashboard is intentionally simple. Extend it to fetch and render the Markdown job files for a richer view.

Safety & recovery
  • Protected paths: docs/safety.md
  • Recovery paths: docs/recovery.md
  • Gate is enforced in GitHub Actions (required for merge)
