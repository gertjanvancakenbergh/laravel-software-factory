# Learning Log

Append-only record of outcomes. Used to distill better conventions, prompts, and protocol rules over time.

**Owner**: Orchestrator (final authority on what gets promoted).  
**Format**: One entry per resolved finding, closed ticket with notable outcome, accepted/rejected proposal, or CI/review lesson.

## Entry template

```md
### YYYY-MM-DD — [short title]
- **Type**: finding | proposal | ci-failure | review-round | merge-decision | other
- **Ticket / ADR**: [link]
- **Agents involved**: [list]
- **Outcome**: accepted | rejected | modified | fixed-after-review | merged-clean | etc.
- **What happened**: One or two sentences.
- **Lesson** (if any): Pattern worth remembering.
- **Promoted?**: no | to conventions | to ADR | to agent prompt | pending
```
