# Domain Glossary

(Agents update this file during grilling.)

## Star Wars API terms

- **Film** — A movie in the Star Wars saga.
- **Character** — A person or being appearing in one or more films.
- **Planet** — A world in the galaxy.
- **Species** — A biological classification of characters.
- **Vehicle** — A ground or atmospheric craft.
- **Starship** — A space-faring craft.

## Factory terms

- **Ticket** — A GitHub Issue that is small enough for one Implementer session.
- **Integration branch** — The branch on which parallel workers merge their work.
- **Worktree** — An isolated git worktree assigned to one Implementer.
